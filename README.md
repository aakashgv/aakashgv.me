# aakashgv.me

Personal site of Aakash Vachhani. Plain HTML/CSS/JS - no build step.

## Edit
- Content: `index.html`
- Look: `style.css` (colors are the CSS variables at the top)
- Theme toggle: `script.js`

## Run locally
Open `index.html` in a browser, or `python3 -m http.server`.

## Deploy
Hosted on Vercel, auto-deploys from the main branch of this repo.
